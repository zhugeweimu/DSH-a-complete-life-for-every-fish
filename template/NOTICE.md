# 来源与原创性（NOTICE）

## 参考过的东西

| 来源 | 许可 | 我们借了什么 | 没借什么 |
|---|---|---|---|
| **Neo-MoFox / booku_memory** | AGPL-3.0 | 记忆表的接口形态（records/tags/memos 的字段组织）、`/api/memories` 这类读写思路 | 没有复制其源码；检索与日志/事件层为自写 |
| **dsh-world** | MIT | 日记、自述、每日回顾的产品思路 | 没有复制代码；实现是文件追加 + 库写入 |
| **BM25 / RRF / bge / ONNX reranker** | 公开算法/模型 | 标准检索做法 | — |
| **Obsidian 镜像** | 产品思路 | “记忆导出成可读 md 文件夹” | 没有依赖 Obsidian |

## 我们自己的部分（主要逻辑）

```
两层结构      日志（事实，不删） / 事件（记忆，可召回）
会话分段      间隔 > 30 分钟 → 上一段关闭
事件拆分      同一段里按类型各成一条，带各自重要度（不互相吞并）
自动抽取      7 类规则 + 寒暄/问句跳过 + 同句收敛
衰减曲线      H = 7 + 365·imp²；floor = 0.3·imp；w ∈ [0,1]
召回打分      相关度 × (0.4 + 0.6w)，另给归一化分
注入边界      只提供 /context 与工具，不自动注入
自述/日记     追加式文件 + 库双写（最初版，不做总结）
文件夹视图    vault/：index + memories/日期 + 日记 + 自述
DSH 适配      工具注册 / 子插件 / 用户模块三种接法
```
