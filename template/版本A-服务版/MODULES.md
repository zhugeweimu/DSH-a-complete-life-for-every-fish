# 模块说明（MODULES）

每个模块按同一模板：**职责 / 输入 / 输出 / 依赖 / 不负责什么（边界）**。

---

## 1. `sql/schema.sql` —— 存储层

- **职责**：定义记忆库的全部表与索引（记录、标签、临时备忘）。
- **输入**：无（DDL 文件）。
- **输出**：一个可直接被 SQLite 打开的库。
- **依赖**：SQLite ≥ 3.35。
- **边界**：只定义结构，不写入任何数据；图谱三表由 `graph_server.py` 首次运行时自建。

表：

| 表 | 作用 |
|---|---|
| `booku_memory_records` | 记忆主表（id/标题/内容/人物/文件夹/时间/重要度/激活时间） |
| `booku_memory_tags` | 标签（多对一） |
| `booku_temporary_memos` | 临时备忘（带过期时间） |

---

## 2. `src/hybrid.py` —— 检索三件套

- **职责**：中文 BM25、向量检索、RRF 融合、语料加载。
- **输入**：`db_path`（SQLite 路径）、查询串、可选向量。
- **输出**：排序后的记忆列表（id/标题/分数/摘要）。
- **依赖**：Python 标准库；向量调用可选（外部 `/v1/embeddings`）。
- **边界**：不做写入、不做重排（重排在 `reranker_onnx.py`）、不做衰减。

关键函数：

| 函数 | 说明 |
|---|---|
| `load_corpus(db_path)` | 从库里读出全部未删除记忆（含标签） |
| `tokens(text)` | 中文二元 + 英文词切分 |
| `BM25(docs).search(q, top)` | 字面检索 |

---

## 3. `src/reranker_onnx.py` —— 重排（可选）

- **职责**：用本地 ONNX 交叉编码器对候选重排。
- **输入**：查询 + 候选文本列表。
- **输出**：分数（越高越相关）。
- **依赖**：`onnxruntime`、`numpy`；模型文件路径由 `RERANK_MODEL` 指定。
- **边界**：模型缺失时返回空/保持原序，不报错退出。

---

## 4. `src/retrieval_server.py` —— 检索服务

- **职责**：把检索三件套包成一个 HTTP 服务，供任意进程调用。
- **输入**：`GET /search?q=&top=&mode=&rerank=&scope=&person=`
- **输出**：JSON 结果列表。
- **依赖**：`hybrid.py`、`reranker_onnx.py`。
- **边界**：只检索，不做记忆写入、不做人物档案。

---

## 5. `src/graph_server.py` —— 图谱

- **职责**：实体、关系边、事件的增查；事件带时间与向量。
- **输入**：HTTP（`/entity`、`/relation`、`/relations`、`/why`）。
- **输出**：实体/关系/事件 JSON。
- **依赖**：SQLite、可选向量服务。
- **边界**：不做记忆正文检索；不做衰减计算。

表（首次运行自建）：

| 表 | 作用 |
|---|---|
| `entities` | 实体（人/物/地点），以 id 为锚 |
| `relations` | 关系边（主语-谓词-宾语 + 证据 + 时间） |
| `events` | 事件（带向量与时间，用于解释“为什么”） |

---

## 6. `src/memory_core.py` —— 统一内核

- **职责**：把检索、图谱、人物档案合成一个服务；对外只暴露一个地址。
- **输入**：HTTP（`/recall` `/remember` `/relation` `/why` `/profile` `/health`）。
- **输出**：召回结果、关系、档案、健康状态。
- **依赖**：`hybrid.py`、`reranker_onnx.py`、`graph_server.py`、`MEM_DB`、`MEM_INBOX`。
- **边界**：
  - 只读记忆库；写入转发给 inbox，避免双写。
  - 不包含情绪计算、语气、人格、平台适配。
  - 不做数据清洗，原始记忆由写入方负责。

---

## 明确排除（不属于记忆本体）

| 排除项 | 原因 |
|---|---|
| 情绪向量 / 关系矩阵 | 属于感情模型，不是记忆 |
| 语音 / TTS / 角色扮演 | 属于表现层 |
| 聊天平台插件与钩子 | 属于接入层 |
| 人格设定与提示词 | 属于角色内容 |
| 前端面板 | 属于 UI |
