# 演示：记忆导出成文件夹之后长什么样

这里的内容由开源版记忆系统真实生成（`vault/`），不是手写的样例。你可以直接点开看。

```
vault/
├─ index.md                  全部记忆的索引（按时间倒序）
├─ memories/2026-10-27/      每条记忆一个 .md
│   ├─ …_第一次见面.md       frontmatter 带 id/时间/类型/重要度
│   ├─ …_她怕黑.md
│   ├─ …_日记·2026-10-27.md
│   └─ …_自述·2026-10-27.md
├─ 日记/2026-10-27.md        一天一个文件，追加式
└─ 自述.md                   身份记录，追加式
```

## 为什么是文件夹，不是网页

- 聊天软件不一定支持 Markdown，网页还要起服务；
- 文件夹谁都能翻：文件管理器、Obsidian、VS Code、记事本；
- 它只是导出视图，事实源仍是 SQLite；删了可以重新导出。

## 对应能力

| 看到的东西 | 来自哪里 |
|---|---|
| `memories/` | 记忆库里的记录（自动抽取 + 手动写入） |
| `日记/` | `/diary` 写入（同时进库） |
| `自述.md` | `/self` 写入（同时进库） |
| `index.md` | 每次导出重建 |

模板在上一层 `template/`，跑起来就能生成你自己的 `vault/`。
